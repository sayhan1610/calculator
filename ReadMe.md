# Calculator

A simple yet stylish calculator built with HTML, CSS, and JavaScript. This project features a clean and modern design with functional buttons, sound effects, and basic arithmetic operations.

## Features

- **Basic Arithmetic Operations**: Supports addition, subtraction, multiplication, and division.
- **Clear and Delete**: Option to clear the entire display or delete the last entered digit.
- **Sound Effects**: Click sound for a more interactive experience.
- **Responsive Design**: Looks great on both desktop and mobile devices.

## Usage

Click on the buttons to perform calculations. The buttons include:

- **C**: Clears the display.
- **DEL**: Deletes the last digit.
- **Numbers (0-9)**: Input numbers.
- **Operators (+, -, \*, ÷)**: Perform arithmetic operations.
- **.**: Decimal point.
- **=**: Computes the result of the calculation.

## Code Overview

- **`index.html`**: The HTML structure of the calculator.
- **`styles.css`**: The CSS for styling the calculator, including modern gradients and button effects.
- **`script.js`**: JavaScript for handling button clicks and performing calculations.

## Example

Here's a brief overview of the main components:

### `index.html`

Contains the structure of the calculator with a display and buttons.

### `styles.css`

Defines the appearance of the calculator, including:

- **Button styles**: Hover and active states.
- **Background patterns**: Radial and conic gradients.

### `script.js`

Handles button clicks and performs calculations:

- **`handleClick(value)`**: Manages button clicks and calls appropriate functions.
- **`appendToDisplay(value)`**: Adds the clicked value to the display.
- **`clearDisplay()`**: Clears the display.
- **`deleteLastDigit()`**: Deletes the last character from the display.
- **`calculate()`**: Evaluates the expression and displays the result.
